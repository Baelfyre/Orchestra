# Agent Instructions

Treat Conductor as the routing authority. Select one specialist for each distinct output, preserve evidence and missing-evidence boundaries, and require approval before risky actions. Never activate Dagger automatically or against production.


## Protected Governance Escalation
If the current run would need to change, relax, except, reinterpret, or supersede the governance blocking that same candidate, freeze the exact candidate/evidence and stop ordinary remediation. Route independent governance analysis through Conductor and require human review. The originating run may recommend but may not execute or consume the protected governance change. Any human-approved exception or amendment takes effect only in a new execution context. `FAIL_POLICY_SELF_MODIFICATION` is a mandatory escalation trigger, not a same-run repair path.
