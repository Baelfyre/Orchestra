# Kontrolled Kaos on Claude Code

The Claude Code package ID is `kaos`. Its existing Conductor skill is invoked as `/kaos:conductor`, because Claude Code namespaces plugin skills with the plugin ID. The package keeps the current specialist and governance behavior.

Validate packaging with `claude plugin validate --strict .`. This check does not prove an interactive host invocation. See [install-guide.md](install-guide.md) and [CLAUDE.template.md](CLAUDE.template.md).
