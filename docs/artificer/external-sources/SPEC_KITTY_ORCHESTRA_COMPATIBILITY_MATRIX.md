## Conflict Analysis Summary

1. **Governance Authority Invariant:** Spec Kitty allows workflow state transitions (e.g. `accept`, `merge`) to trigger completion. In Orchestra, workflow state transition is NOT authority. Only human authorization or delegated phase envelopes permit merge/release actions.
2. **Single Source of Truth Policy Invariant:** Spec Kitty uses standalone portable doctrine packs. In Orchestra, policy definitions in `docs/governance/` and `skills/` are canonical. Manual policy duplication is strictly prohibited to prevent policy drift.
3. **Arbiter Continuity Invariant:** Spec Kitty collapses review and accept into task states. In Orchestra, Arbiter dispositions (`AUTO_CONTINUE`, `WAIT_FOR_EVIDENCE`, `ESCALATE_HUMAN`, `STOP`) govern phase continuity independently of execution unit status.
