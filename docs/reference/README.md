# Orchestra Reference

This is the stable human-readable entry layer for Orchestra documentation.

Use this reference layer to choose a starting point. Follow the linked source documents for detail, and use the machine contracts for exact structured authority. Human documentation does not override `machine/`, runtime policy, specialist skills, or live Git evidence.

## Start here

- [Getting started](getting-started/README.md): installation, host compatibility, updates, and validation.
- [Architecture](architecture/README.md): runtime boundaries, routing, UAI, and machine contracts.
- [Governance](governance/README.md): authority, lifecycle, evidence, and merge boundaries.
- [Integrations](integrations/README.md): hosts, adapters, MCP transport, and capability contracts.
- [Specialists](specialists/README.md): specialist routing and progressive-disclosure knowledge.
- [Releases](releases/README.md): current release, release notes, and qualification evidence.

## Authority boundaries

- [`README.json`](../../README.json) is the repository's machine-readable project entry point.
- [`machine/`](../../machine/) contains canonical structured contracts and projections.
- [`orchestra_runtime/`](../../orchestra_runtime/) contains runtime implementation.
- [`skills/`](../../skills/) contains specialist behavior and progressive-disclosure contracts.
- Historical documents remain evidence for the phase in which they were written; they are not silently rewritten into current authority.
