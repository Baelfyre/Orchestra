## What changed

- Portable host-capability and integration contracts.
- Deterministic transport selection and cross-host conformance.
- Verified GitHub Copilot `/conductor` support.
- Evidence-bounded UAI projections, negative capability testing, and maturity boundaries.
- Preserved Conductor routing consistency across supported host projections.

Clear specialist ownership may use a lightweight direct route, but specialist selection remains a Conductor routing decision. UAI transport selection remains separate from AWF specialist routing.
