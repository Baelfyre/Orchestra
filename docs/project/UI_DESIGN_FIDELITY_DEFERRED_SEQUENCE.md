# UI Design Fidelity Campaign Deferred Sequence

Status: `PLANNED_NOT_ACTIVE`

This document clarifies the execution order for the governed UI design fidelity and design-system campaign.

## Required sequence

1. Complete the current Codex testing and associated evidence/closeout work.
2. Complete, canonically close, or explicitly reclassify all other Orchestra tasks that were already pending before this UI campaign was planned.
3. Re-read live canonical `main`, active pull requests, roadmap state, validation evidence, and continuity records.
4. Only then consider activation of `UIX-0` from `docs/project/UI_DESIGN_FIDELITY_SYSTEM_PLAN.md`.

The UI campaign is a plan only. It is not active implementation work and does not authorize dependency installation, Figma mutation, adapter activation, UI implementation, CI changes, release, deployment, merge, or protected-state mutation.

If Codex testing or another pending Orchestra task creates new remediation or prerequisite work, that work remains ahead of this campaign unless the maintainer explicitly changes the ordering.
