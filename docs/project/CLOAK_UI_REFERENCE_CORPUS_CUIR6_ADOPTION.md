## Decision

Adopt the existing CUIR-4 bounded progressive pattern retrieval capability as supported optional Cloak behavior.

The adopted capability remains advisory and progressively disclosed. It does not become a mandatory full-corpus prompt injection, an automatic host injection path, or a new implementation/runtime authority surface.

## Evidence basis

The CUIR-5 controlled evaluation compared the frozen Cloak path with no CUIR normalized pattern retrieval against the existing bounded CUIR-4 progressive retrieval path.

The deterministic CUIR-5 evaluator permits `ADOPT_OPTIONAL` only when all configured thresholds pass for expected-pattern recall, provenance completeness, bounded-context compliance, authority-boundary compliance, and source-copying violation count.

The canonical CUIR-5 commit records that the exact reviewed tree completed source qualification, signed materialization, full signed-head validation, and zero unresolved review threads before canonicalization.

This evidence establishes only the bounded retrieval-layer result defined by CUIR-5. It does not establish end-to-end LLM output quality, rendered visual correctness, human usability preference, or production effectiveness.

## Supported optional behavior

The supported CUIR capability remains limited to the existing canonical CUIR-4 contract:

- identify at most three relevant UI/UX problem classes;
- retrieve at most five normalized patterns per task;
- prefer project-native requirements, components, tokens, and assets over external inspiration;
- preserve exact provenance and reuse classifications;
- keep general UI icon notice obligations separate from brand-icon rights review;
- preserve Orchestra-native normalization rather than copying source expression;
- keep implementation authority outside Cloak and hand implementation to the appropriate specialist;
- keep default full-corpus injection disabled;
- keep automatic host injection disabled.

## Adoption boundaries

`ADOPT_OPTIONAL` does not authorize or imply:

- mandatory use for every Cloak task;
- source or asset copying from `REFERENCE_ONLY` material;
- external repository execution or dependency installation;
- provider routing or fallback;
- model selection authority;
- implementation, architecture, security, merge, release, deployment, production-mutation, policy, destructive, or installed-integration-refresh authority;
- a claim that a larger corpus is inherently better;
- a claim of end-to-end model, visual, usability, or production benefit.

All existing CUIR-0 provenance and licensing rules remain in force. `REUSE_WITH_NOTICE`, `REUSE_WITH_RIGHTS_REVIEW`, `REFERENCE_ONLY`, and `PROHIBITED` remain distinct dispositions.
