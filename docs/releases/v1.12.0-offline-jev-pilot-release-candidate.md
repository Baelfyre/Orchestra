## Release scope

This candidate adds a repeatable offline validation runner and a stable scenario catalog over the existing JEV contracts and fake transports. It records sanitized local session outcomes for a proposed three-week observation window. The pilot runner blocks network dispatch within its pytest process and stores artifacts outside the repository.

The scenario set preserves upstream evidence gaps, candidate freshness, typed-response validation, request projection, replay rejection, optional-advice behavior, and advisory-only authority. Synthetic answer fixtures are not independent model judgments.
