## Release summary

v1.10.0 packages the post-v1.9.0 Universal Adaptive Integration work and the Conductor routing reconciliation. It keeps one canonical Orchestra governance and specialist-routing model while allowing host capability and transport projections to vary by evidence.

The candidate preserves these boundaries:

## Release notes draft

Orchestra v1.10.0 adds evidence-bounded Universal Adaptive Integration and strengthens Conductor routing consistency across host projections. It introduces a canonical host capability contract, deterministic integration-strategy and transport boundaries, portable projection parity, shadow-only provider capability classification, negative capability testing, and cross-host conformance. It also records maintainer-verified GitHub Copilot `/conductor` support while preserving an unresolved provider/model boundary because Copilot Auto mode did not expose that identity.

The release keeps Conductor as the sole internal specialist router. Clear ownership can reduce routing overhead through a direct single-specialist fast route, but it never bypasses Conductor. Public release remains v1.9.0 until this exact candidate is approved for separate tag and GitHub Release publication.
