## Owner-confirmed v1.12.0 distribution boundary

**Owner statement, recorded 2026-11-08:** Orchestra v1.12.0 is an **AI-assisted project-development plugin**, not a hosted app. The owner does **not** operate a dedicated Orchestra server for this release, and **Apple App Store and Google Play releases are out of scope**. The owner points to the existing installation guides for Antigravity, Codex, Claude Code, and other IDEs.

**Verified installation/support distinctions:** `docs/setup/INSTALLATION.md` and `docs/setup/COMPATIBILITY.md` identify Antigravity and Codex as supported installations. Claude Code has supported **marketplace plugin packaging/installation** but **active runtime continuity remains `SCAFFOLD_ONLY`**. Cursor, Windsurf, VS Code/VSCodium, JetBrains, Zed, and Neovim have **scaffold-only adapters and workspace instructions**, not demonstrated full host integrations. Manual skill loading for local AI systems is documented. The presence of instructions is not independent evidence of current marketplace availability or active host installation.

**Privacy/operational boundary:** A no-server declaration narrows the exposure model and removes the need to invent a backend or mobile-store integration. It does not rule out local persisted memory/continuity data, IDE-host prompt processing, third-party provider retention, owner-operated support communications, or separately enabled telemetry. Those questions remain applicability-scoped rather than assumed absent. If distribution or architecture later changes, reassess this declaration.
